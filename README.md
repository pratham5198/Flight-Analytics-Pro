# Flight Analytics Pro

A complete Data Science and Machine Learning project for analyzing airline flight schedules, predicting flight duration, and generating operational insights using Streamlit.


## Project Overview

This project focuses on airline flight schedule analysis and predictive analytics using Machine Learning techniques.

The application provides:
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Interactive Dashboard
- Machine Learning Models
- Flight Duration Prediction
- Clustering Analysis
- Business Recommendations

Built using Streamlit for interactive visualization and deployment.
